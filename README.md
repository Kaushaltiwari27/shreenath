## 🚀 Overview

A modern, high-end B2B corporate digital presence for **SHREENATH ENTERPRISE**, engineered to reflect a serious global trading and industrial supply operation.

The website is custom-crafted with an original layout, authentic typography, bespoke dark titanium and warm metallic gold color palette, and high-performance WebGL 3D visualizations.

### 🌟 Key Highlights & Features

- **NASA-Grade Photorealistic 3D Globe**:
  - Built with **Three.js WebGL** rendering at 60 FPS.
  - 2048×1024 high-dynamic-range Earth nighttime textures with authentic coastlines and glowing golden metropolitan city lights.
  - Real topographical elevation bump mapping (Himalayas, Western Ghats, Alps, Andes).
  - Dual-layer atmospheric Fresnel glow shaders and 1,200 particle stars in deep space.
  - 3D parabolic curved trade arcs radiating from **Surat HQ** (21.17° N, 72.83° E) with animated multi-particle comet photon pulses connecting key corridors (Middle East, Europe, Asia & ASEAN, Africa, Americas).
  - Full 360° mouse/touch drag rotation, smooth momentum damping, mouse wheel zoom, and raycasting pin selection.

- **100% Form-Free Direct Commercial Desk**:
  - Replaced generic inquiry forms with zero-friction direct B2B channels.
  - Direct 1-click **WhatsApp Chat** with pre-filled product/requirement briefs.
  - Direct **Telephone Call** button connecting instantly to the procurement team (`+91 70411 72623`).
  - 4 physical facility cards detailing operations at Surat HQ, Navsari Hub, Mumbai JNPT Gateway, and Mundra Deep-Sea Port SEZ.

- **Statutory Verification**:
  - Interactive 1-click clipboard copy for **GSTIN** (`24DDHPN8350R1ZS`) and DGFT **IEC** (`DDHPN8350R`).

- **B2B Product & Solutions Catalog**:
  - 6 dedicated product categories: Industrial Materials, Raw Materials, Metal & Steel, Construction Supplies, Commercial Products, and Custom Fabrication.
  - 1-click inquiry routing from any product card directly to WhatsApp with that product's name pre-loaded.

- **Multi-Location Infrastructure Corridor**:
  - Interactive Gujarat & Maharashtra supply corridor detailing proximity to major ports (Mundra, JNPT) and regional logistics networks.

- **Brand System & Visual Identity**:
  - 100% transparent dark-mode official logo with pure white typography and warm gold accents.
  - Custom square "S" gold-steel emblem favicon.
  - Dark titanium palette (`#0B0B0B`, `#111111`, `#161616`) accented with warm corporate golds (`#C9A227`, `#D4AF37`).
  - Typography: `Space Grotesk` (display & badges) + `Plus Jakarta Sans` (body & tabular figures).

## ⚡ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

```bash
# Clone the repository
git clone https://github.com/Kaushaltiwari27/shreenath.git

# Navigate into the project directory
cd shreenath

# Install dependencies
npm install
```

### Local Development

Start the Vite development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

Compile TypeScript and build the optimized production assets:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Visit `http://localhost:4173/` in your browser.
